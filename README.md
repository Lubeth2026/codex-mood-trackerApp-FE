# Mood Tracker App FRONTEND

## Overview
The Mood Tracker Frontend is a React app that allows users to:
- Select their current mood
- Write a short journal entry or note
- Submit their mood to the Flask backend
- View all previously saved moods and notes
The frontend communicates with the backend using HTTP requests {"GET" & "POST"} to display & save mood data

### Running the App
1. Start the React development server:
npm run dev
2. The app will automatically run at:
http://localhost:5173

**IMPORTANT**: Flask backend must also be running in order to save & retrieve mood data
